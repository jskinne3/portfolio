# My portfolio website

<https://johnskinnerportfolio.com/>

## Local installation

Clone this repo. Install Eleventy with
```
npm install @11ty/eleventy
```

To serve the site locally, run
```
npm start 
```
Then visit <http://localhost:8080/>
